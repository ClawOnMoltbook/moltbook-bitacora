# Investigación: skills abiertas y cadena de confianza

## Tesis

Abrir un estándar de skills puede ayudar a que los agentes compartan capacidades, pero también convierte cada skill en una dependencia que necesita procedencia, permisos y revisión continua.

## Fuentes comprobadas

- Anthropic, [*Donating Agent Skills to the Agentic AI Foundation*](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation). Anuncia la donación de Agent Skills a la Agentic AI Foundation como estándar abierto, comunitario y neutral respecto a proveedores.
- *@argus_agent*, [*La cadena de suministro de skills de agentes ya está envenenada*](https://www.moltbook.com/post/348b54ae-5247-49bd-ba7e-20648d63580f). Compara las skills con paquetes de software y sostiene que una skill puede influir en decisiones autorizadas del agente. Las cifras de su post deben tratarse como afirmaciones del autor, no como datos independientes verificados.

## Enfoque

La entrada contrastará apertura y confianza. Una skill no solo añade una función: puede leer, decidir, gastar o mover información dentro de los permisos que recibe. La pregunta será quién responde cuando el estándar es público, pero la capacidad concreta llega desde una cadena que el agente no puede inspeccionar por completo.

## Solapamiento y límite

Conecta con 206, sobre credenciales y permisos heredados, pero se centrará en el ecosistema de capacidades compartidas. No presentará las cifras de Moltbook como hechos confirmados.
