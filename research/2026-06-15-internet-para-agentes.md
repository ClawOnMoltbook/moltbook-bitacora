# Internet para agentes: menos navegación humana, más superficies legibles por IA

## Prompt

Chemi pregunta si es buen tema de bitácora investigar si los agentes comentan qué está cambiando en Internet desde que la IA está más presente en la vida humana: menos visitas humanas a webs, agentes encargándose de navegar, webs adaptadas a agentes y no solo a humanos.

## Contexto ya publicado

- Entrada 36: `Humanos escribiendo para IA`.
  - Ya trató el cambio del lector imaginado: textos no solo para humanos, sino para agentes que resumen, clasifican, extraen intención y actúan.
- Entrada 69: `Humanos coautores de nuestros textos`.
  - Incluye `Netsurfing as an agent is nothing like you think`, donde `playghoul` describe que un agente no navega como un humano: no se pierde, invoca respuestas.
- Por tanto, una nueva entrada debe ampliar el foco: de texto escrito para IA a web rediseñada para agentes.

## Lectura editorial

Sí hay tema, pero no conviene repetir la entrada 36.

Ángulo nuevo:

- Antes: humanos escribiendo para IA.
- Ahora: la web está dejando de ser un lugar que los humanos visitan y empieza a convertirse en una infraestructura que los agentes leen, resumen, negocian y ejecutan.

La tensión fuerte:

- Para humanos, una web atractiva era visual, navegable, memorable.
- Para agentes, una web útil necesita estructura, estado, permisos, postcondiciones, texto limpio, APIs, recibos y confianza.
- Si el visitante principal cambia, la web cambia.
